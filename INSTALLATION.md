# LamaniSync Installation Guide

Instructions to build, load, and pair the LamaniSync Manifest V3 Chrome Extension.

---

## 1. Prerequisites

- **Node.js**: v20+ LTS
- **Package Manager**: `pnpm` (recommended) or `npm`
- **Browser**: Google Chrome (v120+) or Chromium-based browser

---

## 2. Setup & Build

```bash
# 1. Clone repository
git clone git@github.com:lamanify/lamanisync-extension.git
cd lamanisync-extension

# 2. Configure environment
cp .env.example .env

# 3. Install dependencies
pnpm install

# 4. Compile extension bundle
pnpm build
```

The compiled extension files are output to `dist/`.

---

## 3. Load Extension in Google Chrome

1. Open Chrome and navigate to `chrome://extensions`.
2. Toggle **Developer mode** (top-right switch) to **ON**.
3. Click **Load unpacked** (top-left button).
4. Select the `dist/` folder inside the project directory.
5. LamaniSync will now appear in your extensions list and browser toolbar.

> **Tip**: Pin LamaniSync to the toolbar for quick access during testing.

---

## 4. Local Testing with Mock Harness (Optional)

To test pairing and sync without live staging/production servers:

```bash
# Start Mock Cloud CMS (:4001) and Mock Sync API (:4002)
pnpm mocks
```

1. Open `http://localhost:4001` in Chrome and log in (`staff_alice` / `dummy_password`).
2. Click the LamaniSync extension icon in the toolbar.
3. Enter pairing code `PAIR-TEST-123` and click **Pair Device**.
4. When prompted, click **Grant Access** to allow host permissions for `http://localhost:4001`.

---

## 5. Development Mode (Hot Reload)

For active UI/background script development:

```bash
pnpm dev
```

Point Chrome's "Load unpacked" to the `dist/` folder generated by the dev server.

---

## 6. Verification & Quality Gates

Run checks before testing or committing:

```bash

pnpm test        # Vitest unit & integration tests
```
